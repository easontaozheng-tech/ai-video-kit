# AI视频比赛作战台

一个单文件网页工具，用于2小时AI视频比赛：填入主题和创意，自动生成给文字AI和视频AI（Seedance）的全部提示词，并带计时提醒和提交前自检。

## 怎么用

1. 打开网页（GitHub Pages 地址，或直接双击 `index.html`）
2. 主题一公布，填入主题并点“开始计时”
3. 按 1 到 6 步走：设定、出创意、脚本分镜、镜头工坊、剪辑包装、自检提交
4. 每张卡片点“复制”，粘贴给比赛提供的AI
5. 第4步把AI输出的镜头提示词整段粘贴进来，自动拆成镜头并检查问题

## 说明

- 不调用任何AI，也不联网，所有内容只保存在本机浏览器
- 断网也能用：把 `index.html` 存到电脑或手机上直接打开
- 遇到生成问题，点左上角“出问题了”
