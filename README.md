# 即梦AI视频比赛作战台

一个单文件网页工具，用于2小时AI视频比赛：填入主题和创意，自动生成给文字AI和即梦（Seedance 2.0 / 2.5）的全部提示词，并带计时提醒和提交前自检。

## 怎么用

1. 打开网页（GitHub Pages 地址，或直接双击 `index.html`）
2. 主题一公布，填入主题，选好即梦视频模型（Seedance 2.0 或 2.5），点“开始计时”
3. 按 1 到 6 步走：设定、出创意、脚本与参考图、镜头工坊、剪辑与声音、自检提交
4. 文字卡片点“复制”给文字AI；参考图卡片复制到即梦“图片生成”
5. 第4步把AI输出的镜头提示词整段粘贴进来，自动拆成镜头，检查问题后逐条复制到即梦“视频生成”

## 说明

- 不调用任何AI，也不联网，所有内容只保存在本机浏览器
- 断网也能用：把 `index.html` 存到电脑上直接打开
- 即梦的功能和限制以比赛当天的界面为准
- 遇到生成问题，点左上角“出问题了”
